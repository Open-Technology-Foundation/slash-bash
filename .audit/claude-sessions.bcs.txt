## `claude-sessions` — BCS Audit

### BCS0103 · Recommended · [WARN] · Line 21

```bash
declare -r SCRIPT_PATH=$(realpath -- "${BASH_SOURCE[0]}")
```

BCS0103 specifies `realpath -- "$0"` as the canonical form. `${BASH_SOURCE[0]}` is equivalent when the script is directly executed (not sourced), but deviates from the standard pattern. This script has no dual-purpose fence, so `$0` is the correct choice.

**Fix:** `declare -r SCRIPT_PATH=$(realpath -- "$0")`

### BCS0306 · Recommended · [WARN] · Line 61

```bash
[[ -d $dir ]] || die 3 "no sessions for $PWD"
```

BCS0306 requires `${var@Q}` for any path or user-visible string in error messages to handle embedded spaces, newlines, and special characters safely. `$PWD` is unquoted here in the diagnostic sense.
